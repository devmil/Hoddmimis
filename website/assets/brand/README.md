# Hoddmimis icon

`hoddmimis-icon.svg` is the editable color source for the application and web icons. `hoddmimis-symbolic.svg` is the reviewed 16 px monochrome source used by Linux symbolic themes. `scripts/generate-icons.sh` produces and checks the raster application, favicon, touch, and web-manifest sizes.

The icon was created for Hoddmimis and is distributed with the project under GPL-3.0-or-later. It does not reuse the Mimameidr mark.
